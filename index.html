1. Opis programu

Program je webová aplikácia na evidenciu produktov. Údaje sa budú ukladať do spoločnej databázy. Používateľ bude pracovať cez prehliadač.

  • Používateľ: Po prihlásení môže pridávať a upravovať produkty, spravovať kategórie a vyhľadávať záznamy.
  • Administrátor: Má rovnaké možnosti ako používateľ a navyše spravuje používateľské účty a ich oprávnenia.
  • Archivácia: Nepoužívaný produkt sa označí ako archivovaný a nezobrazuje sa v bežnom zozname.

2. Dátový list

Entita Atribút (Pole) Dátový typ Pravidlá
Produkty id, nazov, popis, cena, pocet_kusov, kategoria_id, archivovany INT, VARCHAR, TEXT, NUMERIC, BOOLEAN Názov povinný (do 150 znakov), cena >= 0, väzba na kategóriu.
Kategórie id, nazov INT, VARCHAR(100) Názov je povinný a jedinečný.
Používatelia id, meno, email, heslo_hash, rola, aktivny INT, VARCHAR, TEXT, BOOLEAN Rola (používateľ/administrátor), jedinečný email.

3. Databázové tabuľky

Aplikácia využíva tri hlavné tabuľky: pouzivatelia, kategorie a produkty.

5. Ukladanie údajov a SQL

CREATE DATABASE IF NOT EXISTS e_shop;
USE e_shop;

CREATE TABLE pouzivatelia (
    id INT PRIMARY KEY AUTO_INCREMENT,
    meno VARCHAR(100) NOT NULL,
    email VARCHAR(254) NOT NULL UNIQUE,
    heslo_hash TEXT NOT NULL,
    rola VARCHAR(20) DEFAULT 'pouzivatel',
    aktivny BOOLEAN DEFAULT TRUE
);

CREATE TABLE kategorie (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nazov VARCHAR(100) NOT NULL UNIQUE
);

CREATE TABLE produkty (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nazov VARCHAR(150) NOT NULL,
    popis TEXT,
    cena NUMERIC(12,2) NOT NULL CHECK (cena >= 0),
    pocet_kusov INT DEFAULT 0 CHECK (pocet_kusov >= 0),
    kategoria_id INT NOT NULL,
    archivovany BOOLEAN DEFAULT FALSE,
    FOREIGN KEY (kategoria_id) REFERENCES kategorie(id)
);

6. Údržba databázy

Zahŕňa kontrolu chýb, optimalizáciu, sledovanie voľného miesta, indexovanie a kontrolu používateľských oprávnení.

7. Zálohovanie a archivácia

Denné automatické šifrované zálohy, uchovávané 30 dní, s mesačnou skúšobnou obnovou do testovacej databázy.

8. Bezpečnosť

Používanie hashovania hesiel (napr. BCrypt), Prepared Statements proti SQL Injection a šifrovaný prenos cez HTTPS.

9. Sprístupnenie webu na internete

Nasadenie backendu na server, zabezpečenie domény a SSL certifikátu, oddelené bezpečné pripojenie k databáze.
